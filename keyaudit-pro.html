What it does

Every handoff, accounted for.

The whole key lifecycle — from label to return — without a paper logbook or a group chat.

01

QR labels in seconds

Print durable labels for existing fobs, pegs, and lockboxes. Scanning a label opens the key — no manual lookup.

02

One-tap checkout

Anyone with permission can check a key out in a tap, with the person, time, and expected return recorded automatically.

03

Overdue alerts

Late keys surface first. Managers see what is out, who has it, and when it was due — before it becomes a lost key.

04

Complete custody history

Every checkout, return, move, and status change is logged by key, person, and site. Nothing gets rewritten silently.

05

Roles & sites

Separate access for front desk, sales, service, and managers. Manage multiple properties or rooftops from one account.

06

Audit-ready records

Walk into an audit with a clean history instead of reconstructing it from memory. Filter, review, and export the trail.

How it works

Four steps to a clean key log.

  1. 01

    Set up the site

    Add locations, key types, and the people who can hand keys over.

  2. 02

    Label the keys

    Print QR labels for the fobs and tags already in use. No new hardware required.

  3. 03

    Check out & return

    Scan, assign a person, and set a due time. Returns take one tap.

  4. 04

    Review the trail

    See overdue keys, spot patterns, and export history when it matters.
